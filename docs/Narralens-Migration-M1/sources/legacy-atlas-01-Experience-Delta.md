# 从工作流表单，转向可探索的影片路线

状态：根据本次用户反馈提出的体验增量，供实际操作评审；未代表用户已经验收。正式产品名称及既有技术集成边界不变。

## 1. 本轮需要纠正什么

上一版主要是六个功能工作区加镜头列表。它展示了功能，但不让用户感觉“我正在走进一部影片，并且我的每次选择会改变这条路线”。最关键的变化不是多加光效，而是让缩放成为浏览方式、让视频主动预览、让选择成为主要动作。

产品不是对玩家发布的互动电影，而是作者自己的创作地图。所有分支是创作过程的可能性，最终导出通常仍是单条线性视频。未选择的候选既不占最终片长，也不应该增加渲染工作。

## 2. 一个画布，四种尺度

| 尺度 | 主要看到什么 | 用户的决定 | 进入方式 |
|---|---|---|---|
| 全片 | 章节、论证顺序、各章时间占比与未决节点 | 先完善哪段；结构是否顺畅 | 默认视图、Home、“全片” |
| 章节 | 章内分镜、已选路线、缺口与精修需求 | 逐镜看，或者只处理问题节点 | 点章节、滚轮放大、“章节” |
| 分镜 | 当前镜头与上下文、多个视频、音画/台词/过场类别 | 这一刻如何表达，采用哪个片段 | 点分镜、“分镜” |
| 时间细节 | 源入出点、帧位置、参数、真实音频与字幕对应 | 精确修改已采用内容 | 按需展开；本轮只实现帧定位和有限参数 |

本原型采用连续的时间坐标和尺度阈值：范围大于 260 秒显示章节；56–260 秒显示章内镜头；小于等于 56 秒展开当前镜头候选分支。最小视野 8 秒，最大为全片。阈值属于原型参数，需要用真实长片和屏幕密度调优。

时间不按节点数组顺序随意估算。显示位置映射自整数帧范围；主线时序独立于图形布局。候选分支与被替换镜头占同一个时间区间，不向右虚增八秒。

## 3. 像关卡，但不靠强迫用户点击

每一章是一段论证，每一镜是一个表达决策。已选主线清楚发亮，未选路径保持可见。看不满意就回到检查点，换一种表达。当前缺文件的分支显示“缺素材”，不说“未解锁”。

不添加倒计时、惩罚、抽卡、虚构相关性百分比、付费解锁或强制按顺序推进。允许直接跳到任何章节；“暂时跳过”不删除候选。选择音乐为“无”是合法创作决定，不是扣分。

不能把 90 个镜头 × 6 个类别变成 540 次强制点击。目标生产版由账号模板和导演意图先给出明确标识的推荐路线；作者优先处理低匹配、事实风险、缺文件、风格冲突等异常。自动推荐和人工确认必须分开计数。本轮只实现逐镜选择、跳过和下一未选节点，不伪称已经具备异常识别模型。

## 4. 单镜自动多视频预览

当前类别一次显示最多三个候选。文件可播放且处于视口内，自动静音循环；离屏、隐藏页面或打开上下文面板时暂停。进入一个新分镜后加载这一镜的可见候选，而不是全片 90 镜同时解码。

播放状态来自真实 HTMLMediaElement 事件。文件没解码成功时明确报错，不用假的“播放中”动画替代。自动播放受限时提供启动按钮；减少动态效果偏好下默认不自动播放。

同一起点预览便于比较运动，不代表不同原始素材已经按真实拍摄时间同步。这不是多机位同步剪辑功能。

音轨默认不会三路同时播放；试听音频只保留一个发声对象。画面、解说、音乐、音效、台词、过场可以分别选择，不提前生成它们的笛卡尔积。

用户可以批量导入多个本地视频。文件读取出错逐项提示，不影响其他有效文件；导入不自动采用。素材不足以覆盖当前镜头时，不自动循环、变速或伪造时长。

## 5. 连续创作的具体路径

原话/想法进入起点 → 资料与事实构成上下文 → 形成章节和粗镜头 → 地图出现推荐及未决节点 → 点击一个节点 → 多段视频自己播放 → 选择画面/声音等 → 路径汇合 → 从已选主线看下去 → 遇到未选镜头停下 → 下一轮选择 → 后期与交付问题回到对应节点。

本轮可真实走通的是“现有示例结构 / 本地候选 → 多视频预览 → 选择 → 保存和恢复 → 沿已选源视频路径播放”。起点提取、自动研究、提案生成、预览代理生产和最终合成均是待接入目标，不把录入要求显示成 AI 已完成。

## 6. 采用分支与撤回

已就绪、原创、无外部副作用、只换画面且时长适配的内置样片，可一击采用并立即撤回。它不改变其他五类、相邻镜头、解说块和全片总帧数。

未知使用依据、本地待复核素材、共享解说/台词、边界过场等先展示影响。涉及费用、外传或新生成，在执行之前审批；发布审核不能由采用按钮替代。

历史恢复创建新修订。当前锁保护素材和对应后期参数，不允许恢复绕过。旧方案在确认时遇到新的项目修订要拒绝，不能悄悄覆盖。

检查点是编辑版本，候选分支是可能表达，两者不是同一个概念。回到检查点不自动重新发生成任务；已花费的外部费用也不能被“撤回”假装退款。

## 7. 灵感、资料和后期仍存在，但不再抢占主导航

点“创作起点”看作者原话与主旨；当前镜头打开依据与来源；台词卡显示共享消费者；后期参数只作用当前镜头；终点检查说明剩余发布阻塞。

目标生产版可在地图中呈现证据缺口标记、局部后期待办、封面与标题终点等，但不能把它们和实际视频秒数硬放在同一个坐标空间。辅助任务附着在时间对象上，不计入影片片长。

## 8. 动效与高级感

缩放按钮使用约 360 ms 缓出镜头运动；滚轮与拖动立即响应，不把播放头做成拖尾动画。卡片采用轻微抬升和边框反馈。采用后的主线变亮和下一镜定位解释了状态变化，不靠持续霓虹或旋转制造注意力。

默认低亮度石墨蓝、克制银蓝强调色、明确图文标签。整片地图和当前决策各有一个主视觉，输入、来源和后期按需展开。

可用性目标（未进行用户实验）：首次使用一分钟内能从全片进入一个镜头并比较三段素材；不用翻页找到上一镜；一次只改一个类别；十秒内能撤回刚才的选择。生产性能目标另以真实项目测量，不能用本轮三段小样片推断 4K 性能。
