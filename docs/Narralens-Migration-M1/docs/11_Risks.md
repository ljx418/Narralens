## 4. 弃用旧路线的条件

不是M1B能启动就移除Hypit。必须至少M2受控接管和M4可靠编辑、旧项目恢复证明通过，才能把新项目默认引擎设为OpenFilm；在此之前默认入口可停留在legacy或新项目试验入口。删除legacy只可在完整V1后另立ADR，保留数据和许可证审计。

M1B或M2失败时，默认返回旧适配器，不未经用户同意换第三个主框架。允许修复已定位的上游问题并提交小补丁；没有证据不把“可修复”当已可用。
