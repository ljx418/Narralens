从观点，到每一个镜头。

叙镜把对话、资料、脚本、分镜、素材、声音、时间轴和交付放进一个工作台。OpenMontage 负责创作与素材提案，Hypit 负责真实工程与渲染，叙镜负责把两者变成一个可控、可撤回、可持续生产的导演体验。

首发：10–15 分钟中文时政观点视频 · B站优先 · 5–10 秒软分镜节奏 · 章节清晰但画面过渡自然
10–15 min目标成片
60–180典型镜头规模
3–6局部分镜备选
1 个最终工程事实源

五条不可变原则

Codex 开发时应把这些当成产品合同。

一个工作台

用户不在 OpenMontage、Hypit 和终端间搬 JSON。两个上游能力都隐藏在同一交互中。

先提案再生成

先比较“怎么讲”，再为选中的方案付费生成/获取素材。

局部修改

改画面默认不改旁白；锁定对象必须真正阻止实际写入。

唯一事实源

Hypit Author Source + Run 是最终剪辑事实源，数据库和 OpenMontage 都不是第二条时间轴。

事实可追溯

研究来源与素材许可分开；AI 合成画面不能冒充真实新闻现场。

失败可恢复

生成、适配和渲染失败不能破坏已确认工程；恢复创建新修订。

三维时间轴的意义

X：时间

全片连续时钟，支持章节、镜头、语义和帧级定位。

Y：轨道

画面、字幕、旁白、音乐共享同一时钟，避免各自漂移。

Z：备选

只展开当前范围的 3–6 个设计版本。空间视图用于比较，不创造第二条时间轴。

7 天开发路线

第一周不追求完整 10–15 分钟成片，而是用真实长项目作为母项目，做出其中 3–5 分钟章节的可控精修与真实导出。

D1
底座探测

固定 SHA/许可/依赖；30 秒中文视频预览→导出→重开→局部改→再导出。

Gate

不通过就停在底座，不画假后台。

D2
统一宿主

DirectorPane + Host + 同页触发真实 OpenMontage proposal。

Gate

手工复制 JSON 不算集成。

D3
真实写入

stable identity、同镜区间 edit、revision、locks、事务。

Gate

失败不损坏工程。

D4
多方案

至少 3 个结构差异方案；选中后 materialize 并真实落地。

Gate

不默认生成全部昂贵候选。

D5
复用恢复

视觉变更不重跑旁白；历史、冲突、晚到任务、崩溃恢复。

Gate

锁必须覆盖所有写入路径。

D6–7
真实章节切片

3–5 分钟、20+ 镜头、字幕声音、3 处多方案精修，重开再导出。

Gate

零号用户亲自完成修改压力测试。

一个月

第 2 周

100+ 镜头导航、空间备选生产化、三个选题回归、标题/封面工作区。

第 3 周

StyleProfile、provider/预算、素材检索与生成、稳定字幕/声音。

第 4 周

完整 10–15 分钟闭环、发布前检查、人工发布、反馈回流。

验收不是“页面看起来对”

每个阶段必须有真实工程/真实 MP4 证据。

编辑不破坏目标范围以外镜头不变；preserve narration 时旁白哈希不变。
版本正确过期提案返回冲突；恢复旧内容创建新 revision。
真实重开关闭应用后重开，工程、素材映射和历史仍能恢复。
真实导出预览与 MP4 抽样帧对应；音频、字幕、黑帧检查通过。
事实与许可研究来源和媒体许可分开；合成画面有标记。
10–15 分钟月度 Gate完整章节、自然过渡、标题/封面、字幕、来源清单一起交付。
“不弱于 OpenMontage / Hypit”必须通过同脚本、同素材、相近预算的真实成片与修改压力测试证明，不能只比较功能列表或截图。
