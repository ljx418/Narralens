## Observed integration seams

* `creation-application.ts:153` supplies `undefined` for NativeContextPort; `#openNative` prepares the real workspace and issues the controlled entry, but supplies no `nativeObservation` grant.
* `ProjectContextService.read` calls generic `layoutFor` and engine `inspect` before reading native facts. Created SOURCE_ONLY box/style/volume can fail the legacy M4 completeness check here even though a verified adopted snapshot is legitimate.
* `CommittedSnapshotAuthority.readerForTransaction` already verifies owner, committed transaction, snapshot/source identity, SourceDigest, external-reference absence, media closure, producer lineage and native parsed clip IDs. Its adopted branch validates immutable plan/adoption/source facts and consumer graph, without suppressing generic M4 failures. It returns SnapshotClosure with rights and geometry, but closes read descriptors. That result alone is NOT NativeExpectedSourceFacts.
* `CreatedNativeWorkspaceService.prepare/rootFor` independently copy and verify the actual Studio source. `isPrepared` checks issued object, DB binding, directory identity and root containment; it does NOT synchronously hash all copied file bytes. Do not treat it as a complete expected-proof guard.
* Existing controlled access already calls observation sessionOpened/sessionClosed when a grant is supplied. Gateway ingress and original Studio bridge already implement the closed observation transport. Reuse them, one original editor/timeline/player and one selection authority.

## Selection: same native authority, exact mapping

Implement NativeSelectionMappingPort against the same verified snapshot/consumer graph. Require matching native project, current session/generation, verified document identity and workspace lease. Resolve exact clip IDs to graph entries; deduplicate shot IDs in committed storyboard order, not browser display order. Visual and concept entries may map to the same shot. Reject unknown/duplicate graph IDs or refs to another revision. Narration-only/source/caption/text refs do not imply a particular shot; return null unless their supported range has a verified graph mapping. Do not invent all-shots selection.

Use original Studio `refs` and explicit `range` as the selection source. Bridge selection identity excludes playback `time`, and events are not emitted for every tick: therefore do NOT use changing playhead time as an independent selection authority. For explicit finite range seconds, proposed conversion is floor(start * fps.num / fps.den), ceil(end * fps.num / fps.den), bounded within committed frame_count, half-open and nonempty; test floating boundary values and reject out-of-domain/inverted values rather than silently widening. Clip selection without explicit range uses verified clip ranges. This rounding policy is an internal proposed mapping that MAIN must make explicit in tests; do not claim it is an existing native frame contract. Empty refs/range returns null, not a guessed first shot. Zero-frame project can remain noAck under current profileComplete requirement for mapped selection; do not force a synthetic nonempty selection merely to green it.

Inject this one NativeObservationService as both NativeContextPort and synchronous NativeSelectionVersionPort for adoption guards. Do not create a second selection counter. Repeated equivalent mapped selection retains version; changed or unmappable selection invalidates Ack; after awaits recheck original sequence/session. Context exposes selection only under matching loaded snapshot/revision/session/generation/version, as today.

## Lifecycle and final write boundary

Construct AckStore on the same RevisionStore connection, expected service with real reader and approved loader, then observation service with real mapper. At `#openNative`, after prepare and supervisor.ensure, repeat owner/session/generation and prepared-copy checks; derive native_project_id from actual descriptor. Pass nativeObservation grant with identical project/revision/snapshot/source/workspace/isCurrent facts. Controlled access owns bridge session ID and callbacks; native cookie/Native-CSRF/Origin remains mandatory. UI delegate remains a separate authenticated authority; native observation grants no adoption/write privilege.

Opening replaces the active native session. New editor_view_id, document_epoch, hydration_epoch, invalidated/dirty/failed/unsupported state, changed selection, commit/control movement, logout, supervisor generation change and close must revoke loaded status immediately. In-flight expected proof cannot re-green a superseded profile. Same-session reload may retain sequence bookkeeping, but cannot inherit old hydration as new evidence. Original patch event emission remains on the same Studio; no new frontend clock.

Capture control_revision at comparison/session start: current `#controlRevisionOf` reads currentState again, so comparison against another current read cannot prove it stayed unchanged since open. Add a Host-private captured control revision to issued binding or comparison token and compare it with current DB value. Also review the cached-Ack early return: any cached loaded result must still be invalidated on binding/control/source/workspace movement; do not return loaded solely from matching revision numbers. Keep final synchronous expected.assertCurrent immediately before insertion; if MAIN moves the check into AckStore, use a private callback executed within the same transaction, not an await between guard and write. Current `record` executes transaction before its returned Promise resolves; preserve that ordering and recheck session after await. No SQL schema expansion is necessary. Durable rows are history, never enough to restore live Ack after restart.

Shutdown: stop admitting native opens; close/revoke controlled sessions, invalidate in-flight observations, close expected proofs/retained handles, then dispose native workspace after actual Studio children stop; keep same DB lifecycle ordering. Never delete runtime workspace beneath a live Studio or share a writable root.
