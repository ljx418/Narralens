# Narralens 自动化开发持久记忆

更新时间：2026-10-17

## 用户级执行约束

- 所有自动化浏览器、交互、可访问性、截图和端到端测试必须使用 Headless 模式运行。
- 自动化测试必须无声、无弹窗、不得显示可见浏览器窗口、不得抢占桌面焦点或干扰用户正在进行的工作。
- 不得为了满足“真实浏览器缩放”或桌面验收而自行切换到 headed Chrome、桌面键鼠注入或窗口自动化。若某项门限在 Headless 下无法被真实证明，必须保留为未通过并先修订技术路线或向用户报告，不得用 device scale、viewport 缩半、CSS 注入或截图放大冒充。
- 人工验收只有在用户明确要求并参与时才能启动可见界面；它不属于自动化验收。
- 每次启动浏览器/Host 必须使用隔离临时 profile/fixture，结束后关闭进程并将临时目录移入回收站。

该文件是跨窗口、跨 Agent 的持久执行约束；与旧文档冲突时，以用户最新指令和本文件为准。

## 大步高质量推进约束

- 剩余开发默认按垂直波次推进，不把每个小模块都变成人工审批、完整外审或重复全量报告的停工点。
- 开工前一次冻结整波的跨模块接口、状态机、持久格式、验收 case 和禁止项；模块检查点只运行增量测试、架构 fitness、受影响回归并追加证据，通过后自动继续。
- 每个波次末集中执行一次组合全量回归、一次内部四视角审查和一次独立外审。模块提交用于定位/回退，正式 Gate 绑定组合 commit。
- 优先打通最窄真实垂直链，再扩展负向矩阵，避免先做无法被下一模块消费的临时实现。
- 普通编译、类型、局部测试、可复现 race 或 adapter 差异由 Agent 自动修复并复验，不向用户逐项请求批准。
- 只在架构契约破坏、数据/回退不确定、未经授权费用或外传、真实 Gate 连续两轮无改善、外部限制或需要用户内容/体验/高风险选择时停止。
- 当前四波次为：Wave 1=M2 全部；Wave 2=M3+M4；Wave 3=M5+M6/P0；Wave 4=M7A–D/V1-Full。详细规则见 `docs/handoff-m2-m7d-claude/13_ACCELERATED_DELIVERY_STRATEGY.md`。
