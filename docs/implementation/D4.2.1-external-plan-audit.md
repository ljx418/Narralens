## 4. 非阻断实现风险

1. busboy 最终版本、类型与许可证须在安装时完成锁版和供应链审计。
2. Windows/WSL 的 fsync/rename durability 差异必须真实测试；证据不足时只能声称进程崩溃原子，不得声称断电原子。
3. RSS 探针需与慢消费者 backpressure 事实共同使用，禁止用噪声阈值假绿。
4. Hypit 写后 manifest 变化的 Source 补偿必须先通过 fork 单元/集成及真实 D4.0 回归，Host import route 才可开放。
5. Archify 官方 visual-check 保持 `failed`（Windows Chrome WSL pipe `ECONNRESET`）；9/9 确定性验证与补充 1440×900 人工检查不能改写为自动浏览器通过。
