## 5. 项目对外审建议的技术裁决

- 接受“必须有可观测 NOWRITE 计数”，但不采用全局静态 `ProjectWriteActor.countInvocations()`；全局状态会污染并行测试和多 Host 实例。改用 Host 实例 diagnostics，证明力相同且隔离更正确。
- 接受短选区边界问题，但不采用带最小阈值的百分比桶；GCD 整数向量无浮点与桶边界，适用于 1 帧到长选区。
- 接受 fsync 时序问题，但不把 D4.1 comparison 暂存提升为 D5 的持久任务系统；D4.1 只承诺原子可见、启动清理和损坏拒绝。
- 接受来源构造未定义，但不在 D4.1 虚构 `ProjectTrustManifest`；当前阶段固定空白名单，P0-01 另立契约。
