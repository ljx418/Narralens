## 已发现并关闭的问题

1. **Blocker：UI 上下文与旧 comparison 可错配。** 初版允许结果生成后切换镜头、修改意图/保留项/数量或完成 D3/D4 写事务而继续显示旧结果。修复为：运行中禁用镜头与保留项切换；任何非运行期上下文变化和成功写事务都递增 generation、清除 job/comparison/选择态；新增 UI 回归覆盖。
2. **Blocker：终态 comparison 读取失败可能持续轮询。** 初版在 succeeded 事件后的 comparison GET 失败时仍保持 observer 活跃。修复为终态读取失败立即停止 observer、显示稳定错误并保留用户草稿。
3. **Should-fix：provider 对裸 const/enum 的兼容失败。** 第一次真实调用未产生 `structured_output`，正确失败为 422 且未发布结果。保留完整约束的同时为 const/enum 注入显式推断 type；专项测试通过，独立人工复验一次成功。失败证据没有删除。
4. **Should-fix：ARIA 分组属性不完整。** axe 将三个无 role 的 `aria-label` 分组列为 serious incomplete。为主题、保留项与 fit 控件加入 `role=group`；生产构建复验 0 violations、0 aria-prohibited incomplete。
5. **Should-fix：损坏 final 曾被映射为 404。** 修复为 JSON/schema/语义损坏稳定返回 422 `INVALID_PROPOSAL_SET`，只有 ENOENT 返回 404；每次读取重新执行完整语义校验。

## 正向审计结论

- Runner 草稿无法注入 project/revision/ID/cost；Host 独占可信绑定与审计包装。
- provider schema 无残留 `$ref/$defs`，保留 additionalProperties、数量、enum、const、pattern 等约束；外部/递归引用失败关闭。
- 比较集为单文件原子发布，校验失败没有部分候选；启动仅清理 Host 私有 tmp 命名空间。
- 任意候选数量、帧覆盖、重复 ID、悬空素材引用、非空不受信来源或任意一对伪结构差异都会整套 422。

- API 保持 loopback same-origin + bearer session 边界；comparison 路由二次校验 ID，读取时复核当前 revision。
- 80/80 测试、TypeScript、生产构建、安全扫描和 D4.0 真实回归全部通过；无删除、改名或跳过旧 47 个基线测试。
