## 3. 驳回的误报/不适用建议

| 外审说法 | 事实裁决 |
|---|---|
| 文档 Gate 前必须先落地 fork 代码 | 倒置“计划→内审→外审→实现”的批准流程；新代码不存在不是文档缺陷 |
| `project-write-actor.ts:185` 是 `UN_SUPPORTED_EDIT` | 实际源码为 `UNSUPPORTED_EDIT`；全库检索无 typo |
| 外部 `replace_visual_asset` 与内部 `media.replace` 必须同名 | 它们属于不同边界；显式 Adapter 映射比泄漏上游词汇更正确 |
| 客户端必须传 `preimageSha256` | 不安全且违反所有权；preimage 由 Hypit 当前 revision/AST/磁盘计算 |
| API 应把 `shot_id` 改为 authored/item ID | 违反 D3 已验证的 stable business ID 映射；opaque item ID 不得出 Adapter |
| fixture 的 Window/Clip 同名必然非法 | 固定 Hypit 已真实 compile/build/write/reopen；引用路径区分 semantic outputs |
| Hypit 0.3.1 与 `@hypit/markup@1` 冲突 | distribution 版本与 frontend ABI request 不是同一版本域 |
| `visual-10s.mp4` 与 30 秒工程矛盾 | 10 秒源素材被三个 10 秒窗口复用，工程是 900 帧/30 秒 |
