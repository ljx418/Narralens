## 2. 规格与架构核验

1. D4.2.1 只实现本地 MP4 导入、许可登记与公开库存；没有 materialize、segment binding、composite、impact approval 或 adopt API。
2. `AssetImportService` 独占 upload bytes、manifest 和 import journal 的副作用；`ProjectOperationQueue` 与既有 Source 写共享同项目 FIFO 边界。导入路径不调用 `ProjectWriteActor.execute`，不修改 Source、Run、narration 或 revision。
3. @1 读取、首次新增时原子迁移 @2、失败精确补偿和唯一活跃 manifest 均由真实事务测试覆盖；Hypit fork 固定为 `6fdd8c0f02c17b9970aee6deb4550a70e9d57acf`，支持 expected manifest SHA 与写前后 TOCTOU 复核。
4. inventory 每次重验 realpath、stat 与 bytes SHA；restricted/unknown 如实可见但不可 eligible，generated 不因许可 cleared 而失去 synthetic 标记。
5. UI 文案明确“已登记，未进入时间轴”，没有把登记误称为素材化、准备采用或采用。
