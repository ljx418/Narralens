## 最小体验路线

1. 复查镜头2的修改目标与保留项，点击“准备这个镜头的候选”。
2. 候选就绪后点击“查看候选并比较”，在原播放区位置切换当前/候选示意帧，工程仍为r1。
3. 点击“核对采用影响”，复查变更与保留项，再点击“确认采用这个画面”。
4. 分别观察正在提交、工程r2/编辑区r1、编辑区确认r2三个状态。它们是独立模拟回报，不将受理冒充成功。
5. 点击“继续调整这一镜”或审阅时点击“调整要求，只重做这一镜”；不丢草稿，不重做其他镜头。
6. 打开顶部系统面板，同时编辑目标。它不使用dialog、遮罩、焦点锁；服务/模型/恢复采用独立区域，关闭仅收起视图。

## 演练异常

底部切换情境会重置本页模拟状态，保留目标草稿；这不是工程回退。

| 情境 | 体验与边界 |
|---|---|
| 正常改单镜 | 准备→比较→检查→确认→提交→编辑区确认→继续精修 |
| 媒体服务阻塞 | 说明影响镜头2；打开系统、检查就绪，收到模拟回报后回导演栏继续，不自动采用 |
| 准备时断线 | 冻结最后已知状态，重连核对原任务，不创建新请求 |
| 确认依据过期一次 | 首次确认被拒，版本不变；重核后仍需再次确认 |
| 采用结果未知 | 保持未知；查询不重提、不增加版本、不伪造成功 |

取消准备会使晚到候选失效。系统模型操作具有独立演练生命周期，取消创作准备不取消模型回报。活动准备/提交期间禁止卸载模型。共享ComfyUI只有只读连接检查。

## 保留和改变

- 保留原编辑器空间、M5导演栏位置与单一选区/播放时钟的目标架构；不建立第二应用或第二时间轴。
- 顶部默认摘要，横向轨道展开后只呈现紧凑阶段与当前说明，自动定位当前步骤；顶部定位按钮只定位原导演入口。
- 每个创作状态只突出一个主动作，比较、审批和版本确认分开；系统入口弱化。
- 系统面板采用布局分栏，日常查看不遮住导演栏；窄屏改下方区域，不能据此宣称支持完整原生精剪。
- 日常用户无需输入comparison ID或逐个触发素材化/impact；生产编排与安全检查仍须真实实现，不以本原型代替。
