# S0原型与首轮合同冻结方案

状态：设计候选。不是S0通过，不是CP-A0生产准入，不是A轮已开发。用户已授权完成并汇报S0；本轮不做A生产功能。权威主线仍为PRD v1.2、21体验、35测试族、S0+A/B/C与17任务包，旧Gate不重编号。

## 1. 首轮目标

A轮在一个真实外部驱动端，用本地已授权素材与已有中文录音完成60–180秒可编辑视频、确定性概念画面、改单镜、关闭重开和再次导出。下载、TTS、Comfy生产采用、多驱动抢占、完整后期、长片分别留B/C，不能拿A短片冒充V1。缺真实旁白/素材时显示等待输入，不用空音轨或固定三镜样例假装成功。

## 2. 可操作原型

打开prototype.html。页面一直标明模拟、不会连接Host、不会生成视频。以“为什么雨后会出现彩虹”为具体示例；输入可改，所有预览为示意图。A/B/C按钮显示阶段边界，B的3案选择与C的长片提示属于目标预览，不冒充A范围。

| 场景 | 操作 | 应看到/验证 | 阶段 |
|---|---|---|---|
| PX01 启发简报 | 改主题/时长，补受众，确认简报 | 已知信息不重复问；缺主题不能建立演示工程 | A |
| PX02 业务图 | 建演示工程，点脚本/分镜/旁白/画面节点 | 每节点输入、产物版本、下一步；无技术命令强迫用户执行 | A |
| PX03 精准改动 | 点画面节点，改内容并保存新版本 | 只使画面与组装/导出stale，旁白保留；工程revision不变 | A/B完整 |
| PX04 可信批准 | 准备预览、查看影响、工作台确认应用 | 绑定base/选区/摘要，成功恰好+1，重复点击不能+2 | A |
| PX05 竞态 | 准备后模拟人工改工程，再确认 | 明确409旧预览失效，保留人工修改，要求重新准备 | A |
| PX06 中断 | 保存、模拟关窗重开、断开/重连 | 本地演示持久化；断线指标unknown、不能继续提交；恢复要重验 | A |
| PX07 取消 | 准备后取消、模拟晚到结果 | 不采用；revision不变，结果隔离 | A |
| PX08 导出 | 应用后登记演示导出、再改镜再登记 | 两条导出各自绑定snapshot；下载只给演示JSON，不伪造MP4 | A |
| PX09 选案 | 切B预览，选案2再选案3 | 选中项明确，旧预览/批准失效，选择本身不提交 | B |
| PX10 监控 | 模拟503与确认漂移 | 瞬时资源失败可重试、不置永久attention；确认漂移才阻断 | A/B |

## 3. 原型验收

用户逐项确认PX01..10是否表达目标，尤其E03审阅：默认逐节点查看/编辑结构化产物，最终采用前做范围与保留项比较；概念说明=真实中文可编辑图形+可选生成背景；AI转场不是A必需。资料/脚本/分镜编辑可保存与查看影响，但其完整重算尚未模拟，存在这些未处理分支时禁用画面提交，避免把未重算旁白标作完成。修改意见记录到本包review.html并导出，再由MAIN落盘。浏览器存储只保存原型内容，不能授予生产权限。首次定位/比较≤60秒、恢复入口≤10秒由用户首次体验计时，Agent不能代签。
