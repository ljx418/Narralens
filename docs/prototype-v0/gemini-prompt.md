# 给 Gemini 的 Narralens 前端原型改进提示词

你正在审查并改进“叙镜 · AI 导演工作台 / Narralens”的前端交互原型。请先完整阅读本文件夹中的 `README.md`、`index.html`、两份 JSON 图表源文件，并查看 `assets/current-baseline.png`。

## 事实基线

- 产品面向单人创作者，首发为 10–15 分钟中文时政观点视频，B 站优先。
- 产品主流程只有“想法 → 精修 → 交付”。
- 核心体验是逐镜头可控、局部修改、分项锁、差异确认、撤回/恢复和真实导出。
- OpenMontage 负责提案与素材上游；Hypit Author Source + Run 是唯一最终剪辑事实源；Narralens 是统一控制层。
- 当前项目尚未发现生产源码；现有实现只有文档型 HTML 基线。因此不得把原型交互描述为已接通真实后端。

## 你的任务

改进 `index.html` 的交互体验和视觉表达，输出可直接本地打开的单文件 HTML 原型。保持现有事实、模块名称、用户流程和能力状态，不新增 PRD 未承诺的产品能力。

重点改进：

1. 让真实播放器、导演面板和多轨时间轴成为一眼可读的视觉中心。
2. 让“选择范围 → 输入要求 → 比较 3–6 个方案 → 查看影响 → 采用 → 撤回/恢复”的操作链无需说明也能理解。
3. 让视觉、旁白、时长三类锁清晰但不抢占主任务。
4. 让素材来源、许可、费用、baseRevision 和缺素材状态在采用前可被快速审查。
5. 让 60–180 镜头长项目可以通过章节、缩略轨、语义搜索和帧级编辑分层导航。
6. 为默认、选中、加载、缺素材、版本冲突、锁冲突和写入失败提供明确状态。
7. 支持键盘焦点、减少动态效果以及不依赖颜色的状态表达。

## 视觉约束

- 专业本地剪辑工具感，高信息密度，8px 间距体系，小圆角和低阴影。
- 深石墨工作台为主；青绿色表示已确认，琥珀色表示待审批，红色只表示冲突或失败。
- 不使用紫粉渐变、超大营销卡片、emoji 图标、虚假指标或装饰性数据。
- 播放头必须严格跟帧，不使用滞后缓动。
- 动效 180–240ms；支持 `prefers-reduced-motion`。

## 交付要求

- 保持为单文件 HTML，CSS 和 JavaScript 内联，不依赖构建工具。
- 所有按钮必须有 hover、focus 和 active 状态。
- 原型数据必须明确标记为演示数据。
- 不写入生产源码，不声称已通过真实视频、OpenMontage、Hypit 或导出验收。
- 在页面底部列出你保留的事实约束、改进点和仍需人类决定的问题。
