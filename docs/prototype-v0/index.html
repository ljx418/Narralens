User journey

从定位一句话，到安全采用一次局部修改。

主路径只表达 PRD 已承诺的操作；红色恢复分支对应版本冲突、锁冲突和写入失败。

主操作路径

01 定位内容章节 / 镜头 / 语义 / 时间码
02 建立选区明确 start/end 与当前 revision
03 提出要求描述视觉目标和需要保留的对象
04 比较提案结构、素材、许可、费用、可渲染性
05 采用前确认影响范围、锁、baseRevision、审批
06 写入并验证staging → check → commit → 新 revision

确认后的结果

真实预览Hypit Run 产物，不是独立模拟播放器
撤回与恢复已提交内容通过历史恢复创建新 revision
关闭并重开工程、媒体映射与历史仍然存在
再次导出MP4、字幕与抽样帧验证
标题与封面事实一致性检查后人工确认
交付资产视频、字幕、来源许可、版本记录
冲突 / 缺素材 / 写入失败不覆盖新版，不损坏主 Source，不伪装为可导出完成保留提案 → 重新定位或重试
PRD coverage

本轮只承诺“原型理解正确”。

下面状态防止把审查页的交互模拟误报为产品能力。真实能力状态需要在 D1 及后续阶段用代码、工程和 MP4 证据更新。

已落盘的事实基线

  • 首发用户、内容类型、时长、平台和输出规格
  • 想法 / 精修 / 交付三阶段导航
  • 唯一剪辑事实源和 Adapter 边界
  • 开发里程碑、阶段 Gate 和验收矩阵
  • 事实来源与媒体许可分离原则

本原型已经覆盖

  • 播放器、导演面板、时间轴的统一布局
  • 章节、语义、镜头和帧级导航层次
  • 导演要求、多方案、分项锁和影响确认
  • 采用、revision 更新与失败恢复概念
  • 目标架构、模块边界和核心用户路线

仍需下一轮原型细化

  • 想法阶段：任务摘要、研究、脚本与待核验主张
  • 交付阶段：标题、封面、来源许可和发布前检查
  • 加载、空状态、素材缺失、版本冲突和错误态全套视觉
  • 空间备选视图的展开、预演和回收动画
  • 键盘全路径和窄屏降级体验

当前明确不能声明

  • OpenMontage 或 Hypit 已完成固定与集成
  • 真实 Source 写入、锁、事务、回滚或 revision 已实现
  • 真实视频预览、重开、MP4 导出或帧采样已通过
  • 100+ 镜头性能和 SSE 断线恢复已经验收
  • 本阶段已经进入生产代码开发
