# Native expected-projection input / output candidate v1

Source candidate only, not yet built/imported/tested. The fixed native original math is the implementation authority. MAIN is the only production assembler/caller. This is not a CP31 route/tool, authorization port, new timeline/store/clock, media producer, proof that UI loaded, or alternate source of project facts.

## Authority and input origin

`computeExpectedProjection(input)` is a pure Host-only function. It checks structure/closed supported domain; it cannot authenticate a principal, verify DB currentness, independently establish file bytes/rights, or prove the truth of caller-supplied digest references. `origin:'host_independent'` is a descriptive requirement, **not an authority claim accepted from a browser/Agent**. MAIN must assemble every fact from independently verified snapshot/source, registered asset/probe/rights records and pinned readers/producers before the call and revalidate currentness/session/gates at the real NativeAck boundary. Never expose this helper as a route taking arbitrary input JSON. A `computed` result only means expected math was obtained; it does not grant an acknowledgement or permission.

The input has exactly the keys/types in candidate/expected-projection.d.ts. No `observed_rows`, UI hashes or other hidden expected backfill fields are accepted. All required fields/arrays/profile declarations must exist, including empty arrays. SHA fields are64 lowercase hex; they reference real Host-verified facts in production, not “a correctly shaped hash means verified”. Literal vectors deliberately use hashes of fixture labels and carry **no actual source/media/probe/rights evidence**.

- `format='narralens.native-expected-input@1'`, exact upstream SHAe70d9d93c7bebe3d634ff2caa6f7a738cdde59d3 and `profile='narralens.native-expected-numeric@1'`.
- `binding`: owned project_id/project_revision>=1/immutable snapshot_id/source_digest/actual film_sha256. source_entries is the exact independent closed file set with unique canonical relative paths/hashes; film.html entry must match binding. Full source_digest algorithm/currentness verification belongs to MAIN and is not reinvented here.
- `provenance`: origin host_independent plus real source_manifest/listing digests and nullable rights/media_catalog digests. Null means MAIN independently proved no such registered-media facts apply to this exact closure; it never means unknown/pending/failed. Empty or purely controlled-source concept pages need no fake rights/grant/AssetRegistry identifiers. Any actual registered media/probe requires real nonnull applicable summaries. The helper rejects ui_observed values, but MAIN must also ensure no UI observation was merely relabeled. Facts describe the same exact snapshot/workspace binding, not Host current values substituted after a race.
- `film.file` must be present film.html with matching entry; `film.value` is the independently parsed native server value (including native clip IDs), not an engine/M5 DTO or observed React state. All clips require unique nonempty id, exact canonical relative src, explicit finite numeric at>=0 and time=[from,to], to>from>=0. Relative string placement/implicit duration are unsupported. Optional speed is finite>0; original parser/source validation remains MAIN's responsibility.
- `settings.file` and `markers.file`: explicit present/absent, fixed `.film/settings.json` / `.film/markers.json` path, exact hash/null consistent with closed entries. `.value` must already equal output of the same original parseProjectSettings/parseMarkers; the adapter reuses those functions to check normalization, not another parser. Absent settings must be{}, absent markers[]. A source read/parse failure must not be relabeled absent. Pure normalization exports are available after library build for MAIN to apply to its raw independent source read.
- `clip_refs`: exact one per clip, no extras, matching id/src and source SHA in source_entries. Non-page media uses provenance `{kind:registered_asset,asset_id,rights_digest}` from actual registered source/rights facts. A generated page uses `{kind:controlled_source_artifact,artifact_ref:{id,version,sha256},producer_digest,producer_receipt_digest}` and its actual source file SHA, with **no AssetRegistry entry or rights ID invented for that page**. MAIN must independently resolve artifact/project ownership and the actual controlled writer receipt that binds artifact/input/output-file hash; an arbitrary ScriptRef/tag/sha alone is not sufficient evidence. These references do not confer rights by themselves. Canonical source paths reject absolute paths, traversal/dot/empty segments, backslash/control chars, colon, URL percent escapes/query/hash. Non-page media clips in this first profile must live under assets/ so native file listing/probe behavior is modeled; use a new explicit profile rather than silently resolving other reference forms.
- `media_facts`: unique source_ref tied to closed source SHA, origin host_actual_probe for registered media or independently proved host_deterministic_source for a controlled page, real proof_digest, duration_ms/fps/null and has_audio boolean. Values are native-normalized: duration_ms=Math.round(original positive duration seconds*1000); actualBoolean(probe.audio); actual probe.fps. Never use clip duration as a guessed source duration or assume false/no audio because a probe failed. Every referenced clip must have a fact. Video needs positive source duration and fps; sound needs positive duration; page/still may have null intrinsic duration/fps only when independently known not applicable/not needed for this numeric target projection, not when unresolved. Missing facts mean unsupported, not defaults. The empty project has refs/facts/listing all empty and null applicable rights/catalog summaries; a pure controlled concept page has an actual source-artifact/producer proof and deterministic non-media layout facts, not fake probe/rights records. Root must prove the controlled page has no unlicensed external/embedded media requirements before treating the applicable rights summary as none. A deterministic page fact needs real fixed-writer/source proof from MAIN, not a browser span or an invented probe receipt.
- `video_files_in_native_order`: exact independent native listFiles video order, including unreferenced videos under assets/ in this closed workspace; every listed item has real facts and every closed assets/video entry must be represented. Native sorting is path.localeCompare(undefined,{numeric:true}), not SQL order. MAIN obtains/pins this order from the original reader or proves identical same-runtime ordering; it cannot use UI rows to choose a favorable fallback fps. With explicit fps this field still must be truthful/complete.
- `span_facts` is explicit `numeric_source_only/origin not_used/proof null/values[]`, or `host_attested/origin host_independent/proof_digest/one value per clip`. Numeric-only passes empty spans to original filmShape with real media facts and guess=false; it does not invent a Preview response. Attested spans must come from an independently controlled producer, not UI observed info. Every span id/src agrees with refs, finite at/end/natively known duration, optional positive w/h/reflows; at/end must match the source numeric placement/time/speed within1e-6 seconds. Dynamic scene evaluation/unknown intrinsic facts remain unsupported when required. `look` and unrelated UI objects are excluded from this narrow span DTO.

## UI baseline scope

`ui_profile` explicitly sets pending_drops/preview_error/live_height/browser_preferences to **excluded**. This means the expected calculation models committed baseline with no transient UI inputs; it does **not** prove their absence in an actual view. Any supplied active/unknown/local preference alternative is unsupported in this profile. There is no liveHeight/zoom/solo/Player state parameter to tune the expected result. MAIN must separately reject dirty/failed/unsupported hydration events and verify source/currentness; a hash coincidence cannot wash an active dirty state clean. Browser subtitle preference is outside these two outputs and remains separately unknown/unsupported/project-bound under013. Never compute default success because snapshot cannot determine a UI preference.

## Exact native calls and output

Library pure exports come verbatim from pinned sources: filmShape, filmSrcKind, layoutTracks, trackNamesOf, trackHeightsOf, ownTrackHeight, parseMarkers, placeMarkers, footageFps, parseProjectSettings; canonical is exact013/H-R1 hydrationCanonicalJson. No copies of their algorithm bodies are authored in the adapter. The wrapper only enforces supported input/fact structure and repeats the original ProjectView/useEditorTools projection glue:

1. `tracks=layoutTracks(filmShape(doc,spans,normalizedMediaMap,false))`.
2. `names=trackNamesOf(settings.trackNames??[],doc.tracks)`; `heights=trackHeightsOf(settings.trackHeights??[],doc.tracks)`; add matching stored height to each row exactly like original shownTracks without local live overrides.
3. explicit settings.fps else footageFps of native video blocks sorted by startMs then independent native listing video order, using actual facts.fps. No global clock setter/hook is called.
4. Settings value exactly013 `{settings,resolved_fps,fps_source,track_names,track_heights}`. Empty native blocks => original layout returns[], overlap rows retain native lane/index and apply same saved height/main default to each relevant row.
5. Markers value exactly013 `{placed:[{marker,ms,clip_id}]}` from original placeMarkers on actual computed base tracks. Preserve native parsing, trim/speed/±0.5ms inclusion, order, floating values.

Each output part contains value, canonical_utf8 and sha256 of the exact013 envelope `{format:'narralens.native-hydration-effective@1',part,value}`. No expected-profile label/provenance is inserted into that preimage. Canonical implementation is shared, so arrays/object/string/number semantics match013. input_sha256 separately binds the whole supplied input for diagnostics/cache identity; it is not a new CP run/source digest algorithm. `status:'computed'` includes `not_proven` explicitly listing UI/document/hydration/media/style/captions/currentness/rights/transient absence. Errors return finite unsupported reasons without raw source/path/provider errors.
