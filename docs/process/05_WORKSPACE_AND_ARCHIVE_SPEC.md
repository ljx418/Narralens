# 目录治理与归档规范

只整理Narralens及其登记worktree，不碰同videoWorkLine下其他项目。先盘点Git分支/dirty/untracked/ignored、Orca会话和引用；活跃或不可证静止的工作区不删除。

保留canonical docs、当前源码候选和固定OpenFilm隔离树。原始失败/不足证据、未提交用户工作、合同冻结/旧Gate、素材与运行证明不按文件名“tmp”推断可删。原来被签名或引用的路径保留，新增current入口统一指向历史，不大规模搬动旧文件破坏摘要。

冗余worktree先保分支、dirty diff/未跟踪独有资料与摘要、运行根本地恢复档；核备份后才经Orca移出。node_modules/cache等可重建依赖不进Git；运行媒体/本机配置不擅自上传。归档说明含原路径/HEAD/branch/状态/恢复步骤，不能将“归档”称“验收”。

Git上传分两类：流程和计划；未验收源码恢复检查点。显式路径、敏感值扫描、无force push；不把WIP合main假称通过。公开仓库只放项目所需源/文档/证据，凭据/.env/会话配置排除；发现候选敏感值先核查不打印值，不因用户要备份就上传token。

最新清理清单见cleanup-20261120/，旧原件只追加索引。旧目录迁移使用完整归档和链接映射，不能改历史日志解释为新机器重跑。整理完成必须实核Git状态、远端refs与恢复能力。
