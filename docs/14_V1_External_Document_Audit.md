## 3. 首轮建议

1. 原型主题的无痕模式不属于 V1，不纳入本轮范围。
2. 把未来 SaaS、分发、自动发布等许可证复审触发条件记入决策文档。
3. 把“跨镜能力”收紧为 D1 事实支持且 stable ID 契约通过时才进入，否则转 V1.x 候选。
4. Gate V1 增加媒体重关联耗时与失败率证据。
5. Draw.io 第 7 页下一出门条件改成“内审与外审均无未关闭致命/重大问题”。
6. “不弱于”对照验收在执行前冻结样片、预算与失败次数基线。

## 4. D1 事实项（非文档缺陷）

1. Hypit 扩展点、Author Source/Run 边界与真实命令。
2. OpenMontage pipeline、产物 schema 和 Runner 启动方式。
3. 上游许可证原文与保留标识要求。
4. 参考机器及真实性能基线。

这些事项必须在锁定上游版本和参考机器后用真实环境取证；外审确认当前文档没有把它们冒充为已验证事实。
